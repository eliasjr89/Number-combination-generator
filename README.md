# Number Combination Generator

## 🎲 Description

This is an application to generate random combinations of numbers and stars, similar to the combination generation logic in games like **La Primitiva** or **Euromillions**. Users can generate number combinations with interactive sounds, a history of generated combinations, and copy the created combinations to the clipboard.

## 🚀 Features

- **Generate random number combinations**: The app generates combinations of numbers within a defined range (1 to 50).
- **Generate star combinations**: It also generates combinations of stars within a range of 1 to 12.
- **Combinations without repetition**: The numbers generated do not repeat within the same combination.
- **Interactive sounds**: Sounds for clicks, success, and more to enhance the user experience.
- **Generated combinations history**: Generated combinations are stored in a visual history.
- **Copy combination**: Generated combinations can be copied to the clipboard for easy use.
- **Dark mode**: Option to toggle between light and dark mode for the interface.
- **Multilingual support**: The interface supports multiple languages, including Spanish and English.

## 🛠 Technologies

- **HTML5**: Basic structure of the page.
- **CSS3**: Styling of the interface, including dark mode.
- **JavaScript**: Application logic, including random combination generation and sounds.
- **Audio**: Interactive sounds to enhance the app experience.
- **Clipboard API**: For copying combinations to the clipboard.

## 🔧 How to Use

1. **Generate combination**: Click the "Generate" button to get a random combination of numbers and stars.
2. **History**: Generated combinations are displayed in a history for reference.
3. **Dark mode**: Toggle dark mode on or off using the corresponding button.
4. **Copy combination**: You can copy a combination to the clipboard for easy use.
